This package contains the v32.4 concurrent two-phase backend, optimized candidate
analysis, durable HLAE recording queue, candidate-filter fixes, and benchmark
updates.

The packaged source intentionally does not include a prebuilt GUI executable. Run Build_Parser_GUI.bat on Windows before launching the GUI.

Main changed files:
- gui\Program.cs
- gui\BenchmarkSupport.cs
- gui\BatchSupport.cs
- gui\CandidateFilter.cs
- analyze_frags.py
- Build_Parser_GUI.bat

Behavior preserved:
- Rust full parser/export format
- candidate scoring semantics and detailed output
- existing parsed-export and recording-resource compatibility
- RecordingProfile.cs

Current v32.4 behavior:
- conservative preflight disk estimate before a batch starts
- live disk reservations for concurrent workers
- disk estimate learns upward during the current batch
- byte-weighted phase ETA
- CPU/RAM/disk benchmark telemetry
- per-process wall time, CPU time, and peak working set
- persistent calibration history under Local AppData
- benchmark CSV/JSON files inside each export

See BENCHMARK_DATA.md and CONCURRENT_BATCH_PROCESSING.md.

TF2 STV Parser - View Candidates Filter Cheat Sheet
====================================================

BASIC SYNTAX
------------
+field:value   Include candidates matching the value.
-field:value   Exclude candidates matching the value.
word           Generic include search (legacy behavior, now tokenized).
+word          Generic include search.
-word          Generic exclude search.

Supported fields:
  map      Map name shown in the Map column
  mode     Demo classification (for example rgl_6v6, highlander, or community_public)
  type     Capture type (stv, pov, or unknown; demo_type and capture also work)
  class    Attacker class
  team     Attacker team
  demo     Demo filename/path
  weapon   Weapon used in one of the candidate's kills
  player   Attacker user ID (and attacker name/Steam ID when present in candidate data)
  tag      Candidate analysis tag
  text     Generic candidate JSON/search text

COMBINATION RULES
-----------------
1. Positive values for the SAME named field are OR.
   +class:soldier +class:demoman
   = show Soldier OR Demoman candidates.

2. Positive filters for DIFFERENT fields are AND.
   +class:demoman +map:koth_product_final
   = show Demoman candidates that are also on koth_product_final.

3. Every negative filter excludes a match.
   -map:cp_steel -class:spy
   = hide cp_steel and hide Spy candidates.

4. Generic positive words are AND.
   airshot medic
   = candidate search text must contain both airshot and medic.

5. Matching is case-insensitive. Most named fields allow partial matching.

6. Put a value in quotes when it contains spaces.
   +weapon:"rocket launcher"
   -demo:"old scrim"

COMMON EXAMPLES
---------------
Include only Demoman:
  +class:demoman

Exclude Spy:
  -class:spy

Include Soldier or Demoman:
  +class:soldier +class:demoman

Exclude multiple classes:
  -class:spy -class:sniper -class:engineer

Include only Product:
  +map:koth_product_final

Only RGL 6v6 demos:
  +mode:rgl_6v6

Only SourceTV / STV demos:
  +type:stv

Only POV demos:
  +type:pov

Any Highlander demo (including RGL Highlander):
  +mode:highlander

Hide public-server demos:
  -mode:public

Exclude Steel and Upward:
  -map:cp_steel -map:pl_upward

Product + Demoman, but no Spy candidates and no cleanup tag:
  +map:koth_product_final +class:demoman -class:spy -tag:cleanup

Include Product or Proot, only Soldier or Demoman:
  +map:koth_product_final +map:koth_proot +class:soldier +class:demoman

Hide a particular demo:
  -demo:steelpub_2.dem

Only candidates from a demo name containing "scrim":
  +demo:scrim

Exclude a weapon:
  -weapon:market_gardener

Require a weapon:
  +weapon:scattergun

Filter by attacker user ID:
  +player:35
  +player:#35

Require an analysis tag:
  +tag:airshot

Exclude an analysis tag:
  -tag:cleanup

Generic include/exclude:
  +airshot -cleanup

Example with many filters:
  +map:koth_product_final +map:koth_proot +class:soldier +class:demoman -team:blu -weapon:"market gardener" -tag:cleanup

TEAM NOTE
---------
Use the team value shown by the viewer. Both blu and blue are accepted for BLU.

PLAYER NOTE
-----------
For attacker user IDs, player matching is exact so +player:3 does not accidentally match player #35.

MODE NOTE
---------
Mode is a confidence-based demo classification. RGL labels require both a positive RGL
signal recorded in the demo and a matching 6v6 or Highlander roster; a matching roster
without an RGL signal is labeled simply 6v6 Competitive or Highlander Competitive.

# Lawena recording resources

The packaged build places Lawena's optional recording resources in this folder:

- `custom/` — sound suppressors and the PLDX enhanced-particle VPK
- `hud/` — kill-notice and medic recording HUDs
- `skybox/` — selectable Lawena skyboxes

The application can also use an existing Lawena installation. In the HLAE recording dialog, select the folder that directly contains Lawena's `custom`, `hud`, and `skybox` folders.
